## CTO Decision

### DEF-M04-008

Please resolve this during CW-01.

Reason:

One of the objectives of OCS One is that experienced factory operators should be able to work almost entirely from the keyboard.

If row navigation still requires repeated Tab presses through 10–12 columns, we have not yet achieved that objective.

---

## Required implementation

Implement keyboard row navigation for every ODS data table.

### Behaviour

* ↑ / ↓ → Move between rows
* Home → First row
* End → Last row
* Enter → Open/Edit selected record
* H → Open History (if available)
* Space → Select row
* Esc → Clear selection

The selected row should have a clear visual highlight.

This functionality should become part of **OdsDataTable**, so every future module benefits automatically.

Do **not** implement it only for Cell Receiving.

---

## New ODS Standard

Please add the following standard to the ODS documentation:

**ODS Standard 15 – Keyboard Table Navigation**

Every enterprise data table shall support:

* Row selection
* Arrow-key navigation
* Home / End
* Enter action
* Context shortcuts (where applicable)
* Visible focus indicator

This becomes mandatory for every new module.
