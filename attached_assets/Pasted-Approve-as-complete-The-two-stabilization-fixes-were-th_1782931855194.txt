✅ Finding #1 — Production Orders should become read-only

I approve this.

This is a genuine ERP control issue.

A completed or cancelled Production Order should be treated like:

Posted GRN
Posted MIN
Approved BOM
Dispatch Note

Once finalized, it should not be editable.

The rule I'd implement is:

Draft
Released
In Progress
QC Inspection

→ Editable

Completed
Cancelled

→ Read-only

If a mistake is found after completion, create a new Production Order or use a dedicated correction workflow in the future. Do not edit history.

One additional check I'd ask Replit to perform

Before we declare Factory Ready, I'd ask one more UAT question:

Reference Integrity

Verify that the system prevents deleting or deactivating records that are already referenced.

Examples:

Material used in a BOM
Supplier used in a GRN
