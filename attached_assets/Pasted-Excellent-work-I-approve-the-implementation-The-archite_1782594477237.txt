## Final enhancement before MAT-05 is closed

I want the `/developer/performance` page to become a permanent engineering dashboard rather than a one-time certification page.

Please add the following capabilities over time:

### 1. Historical Performance

Instead of only showing current values, maintain a history of measurements.

Allow:

* Last 10 certification runs
* Trend graphs
* Improvement / regression indicators
* Version comparison (v1.0, v1.1, etc.)

---

### 2. Live Database Health

Show:

* Active connections
* Pool utilization
* Long-running queries
* Average transaction duration
* Slow query list
* Index usage statistics

---

### 3. React Performance

Instrument:

* Component render count
* Slow renders (>16 ms)
* Memoization effectiveness
* React Query cache hit ratio

These should be measured rather than estimated.

---

### 4. Background Monitoring

Record:

* Memory every minute
* CPU every minute
* API latency every minute

Retain a rolling history (for example, the last 24 hours) so trends can be identified instead of relying on a single snapshot.

---

### 5. Export

Allow exporting the complete performance report as:

* PDF
* Excel
* JSON

This becomes part of the certification evidence package.
