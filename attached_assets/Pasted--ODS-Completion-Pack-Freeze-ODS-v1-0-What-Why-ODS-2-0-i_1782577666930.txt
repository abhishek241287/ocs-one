# ODS Completion Pack – Freeze ODS v1.0

## What & Why

ODS 2.0 is complete.

This sprint is **NOT** about building new ERP functionality.

Its purpose is to complete the remaining reusable enterprise UI components so ODS can be frozen as Version 1.0.

After this sprint, all future work should focus on Certification Waves and business modules.

---

# PHASE 1 – OdsMetricCard

Create:

```
src/components/ods/OdsMetricCard.tsx
```

Standard KPI card used everywhere.

Features:

* Icon
* Title
* Value
* Unit
* Trend indicator (↑ ↓ →)
* Trend percentage
* Status colour
* Optional footer
* Optional click handler
* Loading skeleton

Replace KPI cards in:

* Director Dashboard
* Manufacturing Dashboard
* Charging Dashboard
* Packing Dashboard
* Reports
