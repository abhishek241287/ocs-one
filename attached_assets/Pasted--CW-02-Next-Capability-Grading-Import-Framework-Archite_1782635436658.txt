# CW-02 Next Capability – Grading Import Framework (Architecture + Phase 1)

Cell Grading certification is progressing well.

The platform architecture is now frozen.

The next activity is to prepare Cell Grading for future machine integration while keeping the current manual workflow fully operational.

Do not integrate any real machine yet.

---

# Business Requirement

Today:

Operator manually enters grading values.

Future:

Automatic grading machines will generate Excel files.

Later versions may support:

* CSV
* Excel
* PDF
* Word
* Direct Machine API
* OPC-UA
* Modbus

Version 1.0 shall continue using Manual Entry.

---

# Objective

Design the import pipeline so that Manual Entry and future Machine Imports use exactly the same grading engine.

There must never be two grading engines.

---

# Required Architecture

Design the following flow.

```
Manual Entry
        │
Excel Import
        │
CSV Import
        │
PDF Import
        │
Word Import
        │
Future Machine API
        │
        ▼
Import Adapter
        │
        ▼
Validation
        │
        ▼
Preview
        │
        ▼
Operator Approval
        │
        ▼
Existing Grading Engine
        │
        ▼
ECF
        │
        ▼
Audit
```

Manual Entry and Import must produce identical results.

---

# Version 1.0 Scope

Implement only:

✓ Manual Entry

Prepare extension points for:

* Excel
* CSV

Do not implement:

* PDF
* Word
* Machine API
* OPC-UA
* Modbus

---

# Deliverables

1. Review current Cell Grading architecture.
2. Verify that only one grading engine exists.
3. Identify any code duplication.
4. Recommend the cleanest adapter architecture.
5. If beneficial, introduce a generic `GradingImportSource` interface.
6. Produce an Architecture Review.
7. If the review is approved, implement only the extension points required for future Excel/CSV imports without changing current operator behaviour.

No machine integration shall be implemented during CW-02.

The current manual grading workflow must remain the certified reference implementation.
