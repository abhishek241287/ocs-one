## One additional requirement

Before we start MAT-05, I want one permanent addition to ODS.

### ODS Standard 16 – Focus Management

Every interactive component must explicitly define:

* Initial focus when opened
* Focus trap while open (dialogs/drawers)
* Focus restoration when closed
* Visible focus indicator
* Keyboard escape behaviour

This applies to:

* Drawers
* Dialogs
* Command Palette
* Dropdowns
* Date Pickers
* Search Bars
* Data Tables

The objective is that a keyboard user can always understand where focus is and never lose it.

Please document this in the Design System and make it the standard for all future components.
