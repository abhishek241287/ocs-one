# OCS One – Sprint 2

## Engineering Master Data Framework

You are the Lead Enterprise Software Architect for OCS One.

Do NOT build Manufacturing, Inventory, QC, or Battery modules yet.

Your task is to build the **Engineering Master Data System**, which will be the foundation for the entire ERP.

### Objective

Create a reusable Master Data framework that allows OCS Oorja to define all engineering components once and reuse them throughout the ERP.

The framework must be scalable, searchable, version-controlled, and suitable for manufacturing.

---

# General Requirements

Every Master should have:

* UUID Primary Key
* Human-readable Code
* Name
* Description
* Status (Active / Inactive)
* Revision Number
* Effective Date
* Created By
* Created Date
* Updated By
* Updated Date
* Attachment Support (PDF, Image, Datasheet)
* Notes

No hard delete.
Only Activate / Deactivate.

---

# Common Features

Every Master module must support:

* Add
* Edit
* View
* Search
* Filter
* Activate/Deactivate
* Attachment Upload
* Revision History
* Audit Log

No Delete button.

---

# UI Requirements

Use one reusable Master Page template.

Every master module should have the same layout:

* Data Grid
* Search
* Filter
* Add Button
* Edit Drawer
* Details View
* Attachment Section

Build reusable components rather than duplicate code.

---

# Database

Design normalized PostgreSQL tables for every master.

Create relationships so Product Master references BMS Master, Cabinet Master, Cell Master, etc.

---

# API

Create REST APIs for CRUD operations (excluding hard delete).
