# OCS One – Sprint 3.1

## Manufacturing Execution System (MES) – Build Phase 1

You are the Lead Manufacturing Software Engineer for OCS One.

Do not build Inventory, Sales, Accounts, or Customer modules.

Your task is to build the Manufacturing Execution System (MES) for OCS Oorja's LiFePO4 Battery factory.

The MES must guide operators through the manufacturing process and prevent skipping mandatory steps.

---

## Product

Initially support only one product:

OCS Oorja 51.2V 100Ah LiFePO4 Battery (16S)

---

# Production Workflow

Create the following workflow exactly.

1. Create Production Order
2. Generate Battery Number
3. Generate QR Code
4. Allocate Approved Cells
5. Cell Matching Verification
6. Assembly
7. Compression
8. BMS Installation
9. BMS Programming
10. First Charge & Top Balancing
11. Charge/Discharge Test
12. Protection Test
13. QC Approval
14. Packing
15. Ready for Dispatch

No stage can begin until the previous stage has been completed and approved.

---

# Stage Ownership

Each stage is completed by a different operator.

Store:

* Operator

## Battery Creation

Automatically generate:

Battery Number

Format:

BAT-YYYYMMDD-0001

Automatically generate a QR Code linked to the battery record.

The QR code should remain the permanent identity of the battery.

---

## Cell Allocation

Only approved graded cells can be selected.

Each battery requires exactly 16 cells.

Store:

* Cell Serial Number
* Capacity
* Internal Resistance
* Cell Position (1–16)

Validate:

* Capacity difference within company limits
* Internal Resistance difference within company limits

If the selected cells exceed the allowed tolerance, display a warning and require supervisor approval.
