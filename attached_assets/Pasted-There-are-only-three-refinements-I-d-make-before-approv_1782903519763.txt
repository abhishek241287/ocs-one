There are only three refinements I'd make before approving implementation.

1. Material Issue Note (MIN) should be immutable ⭐⭐⭐⭐⭐

After a MIN is posted, it should never be edited.

If someone makes a mistake:

❌ Don't edit the MIN.

✅ Create a reversal document.

Just like accounting journals.

Example:

MIN-00015
↓

MIN Reversal
↓

MIN-00016

That preserves a complete audit trail.

I'd add:

Once a Material Issue Note is posted, it becomes read-only. Any correction must be performed through a reversal transaction. Posted MINs must never be edited or deleted.

2. Product Genealogy should include QC ⭐⭐⭐⭐⭐

Current genealogy is:

Because later, when servicing a product, you'll often ask:

That should be part of its permanent history.

Don't think of MIN as "only for production."

Even if only "Production Order" is used in v1.

That avoids redesign later.

One thing I especially like

This sentence:

"The existing production order IS the work order."

That's the correct decision.

Many ERP implementations create:

Production Order

↓

Work Order

Shop Order

↓

Execution Order

...and end up with four documents representing the same work.

For your current factory, keeping one production document is simpler and easier to operate.
