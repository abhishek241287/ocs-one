GET /upstream?production_order_id=

FROM the catalog Q1 SQL. Response: {

production_order_id, order_number,

inputs: [ { material_id, material_code, quantity_issued, uom,

issue: { note_id, note_number, document_cited },

allocations: [ { lot_id, lot_number, quantity, grn_line_id,

grn_id, grn_number, supplier_id, supplier_name,

document_cited } ],

attributes: [ { attribute_code, value, unit } ]   // via captures

} ] }

Every nested object carries document_cited {type, id} from its hop.

Bulk-issued orders traverse identically (notes linked via bulk_batch_lines

— same note→allocation hops).

GET /downstream?lot_id=

FROM catalog Q2. Response: {

lot_id, lot_number, material_id,

reservations: [ { reservation_id, number, production_order_id,

quantity_active, document_cited } ],

wip: [ { wip_issue_note_id, production_order_id, quantity,

consumed_qty, document_cited } ],

consumptions: [ { confirmation_id, number, actual_qty, document_cited } ],

transfers: [ { transfer_request_id, number, status, quantity,

document_cited } ] }

GET /composition?product_id=  |  ?serial_number=

FROM catalog Q3. Response: {

product: { product_id, serial_number (battery_number), production_order_id },

order: { id, number },

consumed_lots: [ { lot_id, lot_number, material_id, quantity,

document_cited } ],          // LOT level (D-73C-01)

cell_genealogy: [ { cell_lot_id, transfer_id, grn_line_id,

document_cited } ]          // where present

// component_serials: OMITTED until D-73C-01 resolves — never inferred.

}

GET /recall?template_id=&attribute_code=&min=&max=

[&date_from&date_to]

FROM catalog Q4 over attribute_capture_values typed columns (index-backed;

template version scoping mandatory — reject without template_id: 422).

Response: {

criteria: { template_id, attribute_code, min, max, … },

matches: [ { material_id, lot_id, lot_number, grn_line_id, grn_id,

value_num, unit, capture_instance_id, document_cited } ],

downstream: per match, the downstream consumers (lot-level; reuse the

downstream hop, capped at 25 per match with meta.truncated flag) }

Deterministic: same params → same result (INV-GEN-04); no time dependence.
