# One additional security requirement

Before MAT-06 is closed, I want one permanent security safeguard added.

## Security Standard SS-02

Every protected API endpoint shall include an automated authorization test.

For every endpoint:

* Director → expected result
* Supervisor → expected result
* Operator → expected result
* Viewer → expected result
* Anonymous → expected result

These tests should execute automatically as part of the certification suite.

If any endpoint returns an unexpected authorization result, certification fails automatically.

This becomes a permanent regression test for RBAC.
