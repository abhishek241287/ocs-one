My recommendation

I would tell Replit something like:

Before deployment, perform an end-to-end manufacturing workflow verification. Every manufacturing module must consume data from the previous stage automatically. Cell Receiving must consume Material Inventory/GRN. Cell Grading must consume Cell Receiving output. Cell Matching must consume Graded Cells. Production Orders must consume Matched Cells. No module should require duplicate manual entry of data that already exists upstream. This is now the highest commercial-readiness priority.
