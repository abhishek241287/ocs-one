Component Link Validation

During Factory Readiness UAT, I identified an incorrect business rule in Material Master.

This is not a new feature. It is a refinement of the existing validation logic.

Problem

Currently, every Material with Usage Type = Inventory Component is forced to select a Linked Component Master.

This is incorrect.

Usage Type defines inventory behavior, not engineering requirements.

For example:

Cell → Inventory Component → Engineering Master Required ✅
BMS → Inventory Component → Engineering Master Required ✅
Hybrid Inverter → Inventory Component → Engineering Master NOT Required ❌
Lithium Inverter → Inventory Component → Engineering Master NOT Required ❌

Imported finished products are purchased, inspected, serialized and sold. They are not manufactured from a BOM, so they should not require a Component Master.

Required Change

Move the validation rule from Usage Type to Material Category.

Add a configurable field in Material Category:

Engineering Master Required

Yes
No

Validation Rule:

If Engineering Master Required = Yes

→ Linked Component Master is mandatory.

If Engineering Master Required = No

→ Linked Component Master is optional.

No category names should ever be hard-coded.

The validation must depend only on this configurable field.
