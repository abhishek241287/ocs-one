## DEF-CW01-018

This one requires a business decision before writing code.

### Proposed manufacturing rule

When the **first cell belonging to a lot is successfully graded**:

* Lot status automatically changes:

`received → grading`

When **all cells in the lot have been graded**:

`grading → graded`

After the lot enters **grading**:

* Supplier
* Cell Model
* Quantity
* Manufacturing Date

must become immutable.

Only administrative notes or explicitly permitted metadata may be edited thereafter.

This preserves complete manufacturing traceability.

Please implement this state machine only after confirming it aligns with the intended factory workflow.
